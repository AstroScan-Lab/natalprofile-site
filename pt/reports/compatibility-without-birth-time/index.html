💕 Análise de Compatibilidade (Básica)

Compatibilidade de caráter quando a hora de nascimento é desconhecida.

  • 150 ⭐ Telegram Stars
  • 5 capítulos
  • PDF

O que tem dentro

  1. Personalidades: como vocês combinam
  2. Amor: como cada um de vocês ama
  3. Conversas: como vocês se entendem
  4. Sentimentos: o que cada um precisa para ter paz de espírito
  5. O que vocês oferecem um ao outro

Para quem é

  • A hora de nascimento de um ou dos dois é desconhecida.
  • Você quer ver como os caracteres e os jeitos de amar se combinam.
  • Você quer uma análise curta e clara.

O que você informa

Para cada uma das duas pessoas: nome, gênero, data e cidade de nascimento.
